Lead Qualifier

Qualifies inbound HubSpot leads in real time. A webhook triggers a deterministic rules engine and an LLM call grounded via pgvector retrieval in the company's own ICP and sales playbook, then writes the score back to HubSpot and alerts Slack for hot leads. Price Drop→pgvector Retrieval→Grounded LLM→Cited Email

Stock Move Explainer

Watches a stock watchlist daily; on a qualifying price drop, retrieves the company's own SEC risk-factor disclosures via pgvector similarity search and asks an LLM to explain the move using only that retrieved text, citing the exact filing passage or honestly saying no connection was found rather than guessing. Built end-to-end in an AI pair-programming session with Claude Code. Ships with 28 unit tests, an LLM grounding eval suite, and gated CI (ruff + pytest).

Chat With Your Database

Ask a database questions in plain language. Schema retrieval runs on PGVector so the model only ever sees the tables relevant to the question, and every generated query runs inside a database-enforced read-only transaction, not just application-level validation, before a second LLM call summarizes the real results back in plain language.
