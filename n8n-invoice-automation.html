Case study

Invoice Autopilot

An n8n automation that reads invoices for you, so nobody has to type the data in by hand.

View workflow on GitHub

The problem

Invoices arrive as PDFs, and someone retypes them

Invoices land in an inbox as PDF attachments. Each one has to be opened, read, and copied into a system by hand. It is slow, and a single typo in a total or a tax line can go unnoticed.

The build

From inbox to validated record

An email with a PDF invoice triggers the workflow. The text is pulled out of the PDF, and an AI model returns clean fields: vendor, date, items, tax, and total. A code step then checks the math, for example whether the items add up to the total. Invoices that pass are saved to a Data Table. Invoices that look wrong go to a person on Slack to approve or fix.

Email trigger→ PDF text extraction→ AI field extraction→ Math check→ Data Table / Slack
  • Checks pass → saved to Data Table
  • Something looks wrong → Slack message to approve or fix

The workflow

How it works

  • An email with a PDF invoice arrives in the demo inbox.
  • The workflow pulls the text out of the PDF.
  • An AI model reads the text and returns clean fields: vendor, date, items, tax, total.
  • A code step checks the math, such as whether the items add up to the total.
  • If everything checks out, the invoice is saved to the Data Table.
  • If something looks wrong, a Slack message goes to a person to approve or fix.
